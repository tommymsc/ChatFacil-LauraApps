# Chat Fácil: Sin Guardar Número — LauraApps

Aplicación Android independiente de Meta/WhatsApp. Abre conversaciones con enlaces `https://wa.me/`, **sin enviar mensajes automáticamente**.

## Funciones
1. Abrir un chat sin guardar contactos.
2. Selección de WhatsApp y WhatsApp Business (si están instalados).
3. Países y prefijos.
4. Pegar y limpiar números.
5. Preparar mensajes.
6. Historial local.
7. Favoritos.
8. Copiar y compartir enlaces.
9. Plantillas.
10. Recibir texto desde Compartir de Android.

Idiomas español e inglés. No requiere permiso de contactos, SMS ni llamadas. Incluye integración de Google Mobile Ads y UMP con **IDs de prueba para el APK de depuración**. El release permanece bloqueado hasta obtener IDs propios.

## APK
Ir a Actions > Android Debug APK > última ejecución > Artifacts > `ChatFacil-debug-APK`.
El APK de depuración usa `com.lauraapps.chatfacil.debug`.

## Monetización y publicación
Antes de publicar, registrar `com.lauraapps.chatfacil` en AdMob, aportar IDs reales para el paquete de producción, publicar una política de privacidad verificada, revisar el consentimiento y preparar un AAB firmado. No usar IDs de prueba en producción.
